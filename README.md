# محفظتي الاحترافية — التصميم القديم

هذه الحزمة تعيد تصميم التطبيق القديم الكامل كما كان قبل اعتماد دورة الزكاة في 3 شعبان. تشمل الواجهة القديمة ونظرة عامة والاستثمارات والدخل والأرصدة والعمليات والزكاة والصحة والنسخ.

تبدأ النسخة العامة بخزنة فارغة ولا تحتوي على بيانات مالية مضمنة. لاستعادة بياناتك استخدم ملف النسخة الاحتياطية من داخل تبويب الصحة والنسخ، إن كانت النسخة الاحتياطية متوافقة مع هذه البنية القديمة.

لا ترفع ملفات JSON الاحتياطية إلى GitHub لأنها تحتوي على بياناتك المالية.


## حالة المراجعة

تم اختبار الخزنة الفارغة، البيانات الناقصة، جميع التبويبات، والحفظ والاستعادة من JSON. تبدأ النسخة بخزنة فارغة عمدًا ولا تتضمن بيانات مالية شخصية داخل الكود.
