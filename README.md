# محفظتي الاحترافية

تطبيق ويب عربي محلي لإدارة المحفظة والاستثمارات والدخل والعمليات والزكاة الهجرية. النسخة العاملة هي `index.html` كمصدر واحد مستقل، ولا تعتمد على مزامنة سحابية أو حسابات خارجية.

## المزايا

- حفظ تلقائي محلي داخل المتصفح.
- فلاتر العمليات حسب النوع والتاريخ مع عدد السجلات والصافي وإجمالي الحركة والمعادل بالجنيه.
- فلتر الدخل حسب السنة مع إجماليات ورسم الاستثمار الشهري.
- فلاتر زمنية لكشوف الأصول وتحليلات الحركة.
- رسوم النظرة العامة وكشوف الأصول.
- نظام زكاة ديناميكي يبدأ في 3 شعبان مع أرشفة الدورات.
- إضافة وحذف العمليات مع تأكيد قبل الحذف.
- تنزيل النسخة الاحتياطية JSON واستعادتها من ملف أو لصق النص أو السحب والإفلات.
- PWA والعمل دون اتصال بعد أول تحميل، مع تحديث شبكة آمن وإصدار cache متجدد.

## الملفات المطلوبة للنشر

ارفع الملفات التالية معًا إلى GitHub Pages:

- `index.html` — التطبيق العامل.
- `manifest.json` و`icon.svg` — التثبيت كتطبيق.
- `sw.js` — العمل دون اتصال وتحديث الكاش.

لا ترفع ملفات النسخ الاحتياطية التي تحتوي على بيانات مالية شخصية.

## الاستخدام الآمن

نزّل نسخة JSON احتياطية دوريًا واحتفظ بها خارج المستودع. الفلاتر لا تعدّل البيانات، والاستعادة لا تستبدل البيانات إلا بعد نجاح التحقق والتأكيد.
