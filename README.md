# محفظتي الاحترافية

تطبيق ويب عربي PWA لإدارة المحفظة الاستثمارية، الذهب، البورصة، الكريبتو، السيولة، العقار، شهادة فيصل، والزكاة — يعمل **محليًا بالكامل** دون أي اتصال خارجي.

## 🔐 الخصوصية

- **لا بيانات مضمّنة**: تبدأ بخزنة فارغة.
- **بدون اتصال**: لا Google Fonts، لا تحليلات، لا سيرفرات.
- البيانات تُحفظ في `localStorage` (JSON).
- ⚠️ **الحفظ غير مشفّر**: من يملك وصولًا للجهاز يمكنه قراءة البيانات. احفظ نسخك الاحتياطية في مكان آمن.

## ✨ المزايا

- 📊 نظرة عامة على توزيع الأصول مع شريط بصري.
- 🗓 **نظام سنوات**: تصفية العمليات والدخل حسب السنة.
- ⚡ **زر عائم "+"** للتسجيل السريع.
- 💰 تعديل أسعار الدولار والذهب مباشرة.
- 📈 شهادة فيصل برصيد تراكمي.
- 🕌 زكاة بدورة هجرية دقيقة (3 شعبان → 2 شعبان) محسوبة بأم القرى.
- 🌓 وضع ليلي/نهاري محفوظ + احترام `prefers-color-scheme`.
- 📱 PWA قابلة للتثبيت + تعمل دون اتصال.
- ♿ إتاحة كاملة: `aria-*`, `focus-visible`, `prefers-reduced-motion`.
- 💾 تصدير/استيراد JSON آمن مع تحقق.

## 🚀 التشغيل

افتح `index.html` مباشرة أو ارفع الحزمة على GitHub Pages.
