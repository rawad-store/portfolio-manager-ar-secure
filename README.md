# محفظتي الاحترافية — التصميم القديم مع زكاة 3 شعبان

تطبيق عربي محلي لإدارة المحفظة، محافظًا على التصميم القديم والرسوم البيانية والتبويبات الأصلية، مع إضافة دورة زكاة هجرية ديناميكية تبدأ في 3 شعبان.

## نظام الزكاة الديناميكي

- يحدد التطبيق السنة الهجرية الحالية باستخدام تقويم أم القرى المتاح في المتصفح.
- يحسب تاريخ 3 شعبان الميلادي تلقائيًا.
- يعرض بداية الدورة ونهايتها وموعد الدورة التالية.
- يثبت أساس الزكاة عند أول تشغيل للإصدار الجديد على إجمالي المحفظة الحالي إذا لم يكن أساسًا محفوظًا سابقًا.
- يمكن مراجعة أساس الدورة وتعديله يدويًا من شاشة الزكاة.
- عند الانتقال إلى دورة جديدة بعد 3 شعبان، تُرحّل الدورة السابقة إلى السجل وتُفتح دورة جديدة وتُصفّر المدفوعات.
- يحسب المستحق والمتبقي على أساس الدورة الثابت، وليس على قيمة متغيرة عشوائيًا طوال السنة.
- يحتفظ بسجل الدورات السابقة.

## البيانات والخصوصية

تبدأ النسخة العامة دون بيانات مالية مضمنة داخل الكود. يمكن استعادة ملف JSON من تبويب **الصحة والنسخ**. ملفات النسخ غير مشفرة وتحتوي على بياناتك، لذلك لا ترفعها إلى GitHub أو أي موقع عام.

## التشغيل

ارفع `index.html` و`README.md` إلى GitHub Pages. بعد فتح النسخة الجديدة، استعد ملف النسخة الاحتياطية ثم راجع **أساس دورة الزكاة** مرة واحدة، خصوصًا إذا لم يكن لديك رصيد موثق في يوم 3 شعبان الماضي.

## رفع النسخة الاحتياطية كملف

1. افتح تبويب **الصحة والنسخ**.
2. اضغط حقل **إرفاق ملف النسخة الاحتياطية**.
3. اختر ملف `portfolio-backup-YYYY-MM-DD.json` من الهاتف أو الكمبيوتر.
4. راجع اسم الملف وحجمه الظاهرين.
5. اضغط **استعادة الملف المرفق**.
6. وافق على رسالة الاستبدال.

يمكن أيضًا سحب ملف JSON وإفلاته داخل مربع الرفع على الكمبيوتر. يبقى خيار لصق النص متاحًا كبديل. يتم رفض الملفات الأكبر من 10 ميجابايت أو الملفات غير المتوافقة، ولا يتم حذف البيانات الحالية عند فشل التحقق.

## الفلاتر والتحليلات

- تبويب **الدخل**: فلتر حسب السنة، مع إجمالي الدخل والمحوّل والمستثمر، ورسم الاستثمار الشهري.
- تبويب **العمليات**: فلتر حسب النوع ومن/إلى، مع عدد العمليات وإجمالي الجنيه وUSDT والذهب، ورسم كثافة العمليات الشهرية.
- كشوف الأصول: فلتر زمني موحد للذهب والبورصة والكريبتو والمكتبة والعقار والنقدية والشهادة، مع عدد السجلات وإجمالي الحركة.
- الرسوم الموجودة في النظرة العامة وكشوف الأصول تستجيب للحسابات والبيانات الحالية، ولا تستخدم بيانات تجريبية.

بعد تغيير أي فلتر، تظهر النتائج والإجماليات الخاصة بالفلتر مباشرة. لإلغاء الفلتر اختر **كل السنوات** أو امسح تاريخي البداية والنهاية، ثم اترك نوع العملية على **كل الأنواع**.
