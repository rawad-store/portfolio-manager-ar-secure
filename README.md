# محفظتي الاحترافية — النسخة النهائية

تطبيق عربي محلي لإدارة الأصول، العمليات، الدخل، شهادة فيصل، والزكاة. لا يحتاج إلى كلمة مرور أو خدمة سحابية، ويحفظ البيانات داخل متصفح الجهاز.

## المزايا

- تعديل الأصول والأسعار من تبويب نظرة عامة.
- إدارة عمليات المحفظة مع الوصف والتاريخ والمبلغ والحذف.
- تسجيل الدخل الشهري بالريال والمبلغ المحول والمستلم بالجنيه.
- شهادة فيصل مع أصل الشهادة ونسبة كل ربع مالي وحساب تراكمي.
- دورة زكاة تبدأ في 3 شعبان وتنتهي في 2 شعبان من السنة التالية.
- حساب موعد 3 شعبان الميلادي تلقائيًا باستخدام تقويم أم القرى المتاح في المتصفح.
- تثبيت أساس الزكاة عند بداية الدورة وأرشفة الدورة السابقة تلقائيًا.
- تنزيل نسخة JSON واستعادتها من الهاتف أو الكمبيوتر.
- تحويل تلقائي للنسخ الاحتياطية القديمة التي تحتوي على الأقسام `man` و`tx` و`im` و`cert` و`zk`.
- ترحيل تلقائي للتخزين المحلي القديم `wlt1` عند فتح النسخة الجديدة على نفس الجهاز.
- Service Worker محدث لتقليل مشاكل الكاش.

## الاستعادة

من تبويب **النسخ والاستعادة** اختر ملف JSON، ثم اضغط **استعادة الملف المحدد** ووافق على الاستبدال. النسخ غير مشفرة، لذلك لا ترفعها إلى GitHub أو أي موقع عام.

## النشر

ارفع الملفات التالية معًا إلى مستودع GitHub Pages:

```text
index.html
app.js
manifest.json
sw.js
icon.svg
README.md
```

بعد التحديث امسح بيانات الموقع القديمة أو افتح الرابط في نافذة خاصة أول مرة. هذه النسخة تبدأ بخزنة جديدة إذا لم تجد بيانات محفوظة، ولا تحذف ملف النسخة الاحتياطية.
