# محفظتي الاحترافية

تطبيق ويب عربي محلي لإدارة المحفظة والاستثمارات والدخل والعمليات والزكاة الهجرية. المصدر ملف واحد مستقل `index.html`، بلا حسابات ولا مزامنة سحابية. تبقى البيانات في متصفح كل جهاز.

## المزايا

- حفظ تلقائي محلي داخل المتصفح.
- نظرة عامة: إجمالي الثروة، خريطة التوزيع، المقارنة بالأهداف مع المبلغ المطلوب لإعادة التوازن، والرصيد الربعي مع نسب النمو.
- كشوف الذهب والبورصة والكريبتو والنقدية والعقار والمكتبة، مع فلاتر زمنية.
- شهادة فيصل: إدخال النسبة المعلنة نهاية كل ربع، وتُحتسب بفائدة مركّبة عبر السنوات في الإجمالي، مع حركات رأس المال وتنبيه للأرباع الناقصة.
- فلاتر العمليات والدخل حسب النوع والتاريخ والسنة، ورسم آخر 12 شهراً.
- زكاة هجرية: دورة تبدأ 3 شعبان، وأساسها يتبع ثروتك حتى التاريخ ثم يُثبَّت ويُؤرشف، والتاريخ الميلادي للمعرفة فقط.
- فحوصات صحة البيانات.
- زر إخفاء الأرقام عند عرض الشاشة للآخرين.
- نسخ احتياطي JSON: تنزيل، واستعادة من ملف أو نص أو سحب وإفلات.
- PWA يعمل دون اتصال بعد أول تحميل.

## الملفات المطلوبة للنشر

ارفعها معاً في مجلد واحد على GitHub Pages:

- `index.html` — التطبيق.
- `manifest.json` — بيانات التثبيت.
- `sw.js` — العمل دون اتصال.
- `icon-192.png` و`icon-512.png` و`icon-maskable-512.png` و`apple-touch-icon.png` — الأيقونات.

لا ترفع ملفات النسخ الاحتياطية، فهي تحتوي بيانات مالية شخصية.

## التثبيت على الهاتف

افتح الرابط مرة واحدة بالإنترنت ثم أضفه إلى الشاشة الرئيسية. على آيفون استعد النسخة الاحتياطية بعد الإضافة، لأن التخزين منفصل عن Safari.

## تحديث التطبيق

عند رفع نسخة جديدة غيّر `VERSION` في أول `sw.js` (مثل `v3` إلى `v4`). يجلب التطبيق أحدث نسخة عند توفر الإنترنت، ويستخدم المخزّنة عند انقطاعه.

## الاستخدام الآمن

نزّل نسخة JSON احتياطية دورياً واحتفظ بها خارج المستودع، فمسح بيانات المتصفح يحذف كل شيء. الفلاتر لا تعدّل البيانات، والاستعادة لا تستبدل البيانات إلا بعد التحقق والتأكيد.
