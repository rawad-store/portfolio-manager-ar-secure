# محفظتي الاحترافية

تطبيق ويب عربي لإدارة المحفظة الاستثمارية: الذهب، البورصة، الكريبتو، النقدية، العقار، الشهادة، والزكاة.

## المزايا

- 🔐 **تشفير محلي كامل** — AES-GCM 256-bit + PBKDF2-SHA-256 (600,000 دورة).
- 🔒 **قفل تلقائي** بعد 5 دقائق، وعند تبديل التبويب، وزر قفل يدوي.
- 📊 **9 تبويبات**: نظرة عامة، استثمارات، دخل، أرصدة، عمليات، زكاة، صحة، سنوات، تحليلات.
- ⚡ **إدخال سريع** بخمسة أصول و10 أنواع فرعية.
- 📈 **رسوم بيانية SVG** أصلية بدون مكتبات.
- 🗂️ **أرشفة سنوية تلقائية** وسنة زكاة متجددة.
- 💾 **نسخة احتياطية مشفرة** قابلة للاستعادة على أي جهاز.
- 📱 **PWA** — يعمل بدون إنترنت بعد أول فتح.
- 🌙 وضع ليلي + دعم كامل للعربية RTL.
