# محفظتي الاحترافية

تطبيق ويب عربي لإدارة المحفظة الاستثمارية ومتابعة الذهب والبورصة والكريبتو والسيولة والعقار والمكتبة والشهادة.

## المزايا

- فلاتر العمليات حسب النوع والسنة مع إجماليات ج.م وUSDT وذهب 24 وعدد النتائج.
- شهادة فيصل بجدول أرباع مالية قابل للتعديل؛ يمكن تغيير نسبة ربح كل ربع، ويُرحّل الربح المستحق تلقائيًا إلى الرصيد التراكمي.
- الرسوم البيانية والتحليلات الشهرية والسنوية حسب نوع العملية.
- نظام متعدد السنوات مع فتح السنة الجديدة وأرشفة السنوات السابقة.
- إدارة سنوات الزكاة تلقائيًا ويدويًا.
- نسخ احتياطي واستعادة بصيغة JSON.
- حفظ تلقائي محلي بعد كل تعديل، مع دعم التخزين المستمر في المتصفح.
- PWA قابلة للتثبيت على الهاتف والكمبيوتر والعمل دون اتصال بعد أول فتح.
- الوضع الليلي وتصميم متجاوب مع الهاتف.

## التشغيل والتثبيت

افتح الموقع من GitHub Pages:

(https://rawad-store.github.io/portfolio-manager-ar-secure/)

على الهاتف، افتح قائمة المتصفح واختر **إضافة إلى الشاشة الرئيسية** أو اضغط زر **تثبيت** داخل التطبيق إذا ظهر.

## حفظ البيانات والخصوصية

هذا الإصدار لا يستخدم مزامنة سحابية. تُحفظ البيانات تلقائيًا في تخزين المتصفح على الجهاز الحالي، لذلك يجب تنزيل نسخة JSON احتياطية دوريًا من تبويب **الصحة والنسخ** ونقلها يدويًا إلى أجهزتك الأخرى ثم استعادتها هناك.

لا تضع رمز GitHub أو أي مفتاح سري داخل `index.html`؛ ذلك يعرّض المستودع والبيانات للاختراق.
