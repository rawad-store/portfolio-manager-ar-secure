# محفظتي الاحترافية

تطبيق ويب عربي لإدارة المحفظة الاستثمارية، الذهب، البورصة، الكريبتو، السيولة، العقار، الشهادة والزكاة.

## الخصوصية والحماية

- النسخة المنشورة لا تحتوي على أي بيانات مالية أو أسماء أو أرصدة حقيقية؛ تبدأ بخزنة فارغة.
- البيانات تُشفّر محليًا باستخدام AES-GCM.
- اشتقاق المفتاح باستخدام PBKDF2-SHA-256 بواقع 600,000 دورة.
- لا يتم حفظ كلمة المرور نفسها.
- يتم اشتقاق مفتاح الجلسة مرة واحدة وإعادة استخدامه أثناء الجلسة، مع IV عشوائي جديد لكل حفظ.
- قفل يدوي وقفل تلقائي بعد 5 دقائق، والقفل عند إخفاء الصفحة أو تبديل التبويب.
- سياسة CSP مضافة لتقليل مخاطر الحقن.
- لا توجد مزامنة سحابية أو مفاتيح GitHub داخل الصفحة.

## استعادة البيانات على جهاز جديد

1. نزّل النسخة الاحتياطية المشفرة من الجهاز القديم.
2. افتح التطبيق على الجهاز الجديد.
3. في شاشة إنشاء الحماية اختر ملف `.vault.json`.
4. أدخل كلمة مرور النسخة الاحتياطية.
5. اضغط **استعادة النسخة قبل إنشاء الخزنة**.

إذا غيّرت كلمة المرور بعد إنشاء النسخة الاحتياطية، استخدم كلمة المرور التي كانت فعالة وقت أخذ تلك النسخة.

## المزايا الأخرى

- فلاتر العمليات حسب النوع والسنة مع إجماليات الجنيه وUSDT وذهب 24 وعدد النتائج.
- شهادة فيصل بأرباع مالية قابلة للتعديل وحساب تراكمي موحد.
- رسوم بيانية وتحليلات شهرية وسنوية.
- نظام سنوات وأرشفة سنوية وإدارة سنوات الزكاة.
- نسخ احتياطي مشفر واستعادة آمنة.
- PWA قابلة للتثبيت والعمل دون اتصال بعد أول فتح.
- تصميم متجاوب ووضع ليلي.

## نسخة التشغيل بدون كلمة مرور

هذه الحزمة لا تعرض شاشة دخول ولا تستخدم تشفيرًا محليًا. تحفظ البيانات بصيغة JSON في تخزين المتصفح، لذلك يمكن لأي شخص يصل إلى الجهاز أو بيانات المتصفح قراءتها. لا ترفع ملفات النسخ الاحتياطية إلى GitHub. النسخ المشفرة القديمة لا تُفتح تلقائيًا في هذه النسخة؛ احتفظ بها منفصلة.
